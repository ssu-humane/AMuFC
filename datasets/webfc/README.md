# WebFC (Web Fact-Checking)

WebFC contains 621 test claims with gold verdicts, filtered text evidence,
and retrieved images.

[Dataset on Hugging Face](https://huggingface.co/datasets/humane-lab/WebFC)

## Setup

After installing the AMuFC environment, run this command from the repository root.

```bash
python datasets/webfc/process_dataset.py --from-hf --output webfc.json
```

The script downloads the JSONL and image archive, extracts the images to
`webfc-images/`, and writes `webfc.json` with gold
verdicts and absolute image paths.

If you already downloaded the files, pass them directly.

```bash
python datasets/webfc/process_dataset.py \
    --input /path/to/webfc-fcfilter-url.jsonl \
    --image-zip /path/to/images.zip \
    --output webfc.json
```

## Output Format

The prepared JSON is an array of records. Each record has the following shape.

```json
{
  "claim_id": "p_24_2",
  "claim": "The claim text.",
  "evidence": "Evidence 1: The retrieved evidence summary.",
  "source_url": "https://www.politifact.com/factchecks/2024/sep/25/speaker/article-slug/",
  "image_filename": "p_24_2_0.jpg",
  "label": "refuted",
  "image": "/path/to/AMuFC/webfc-images/p_24_2_0.jpg"
}
```

Labels are `supported`, `refuted`, and `NEI`. The `source_url` identifies
the PolitiFact article and can reveal the verdict. Use it for provenance checks.

## Use with AMuFC

Run evaluation from the repository root with `scripts/cfg/dataset/webfc.yaml`.
Its `test_ret_datapath` points to the file generated by the setup command.
Set `dataset_split: test` and `dataset_info: ret` in the inference config.

For verifier training, set `train_verifier_datapath` in a separate
dataset config and use an independent held-out set for evaluation.
